# 第 12 章：焊接、调试与返修——让第一块板亮起来

> **开门一句话：**第一次上电的目标不是“功能全对”，而是“没有东西在悄悄发热，且每个异常都能被解释”。

## 学习目标

读完这章，你能做到：

- 按“目视—测短路—限流—上电—测轨—测电流—时钟—编程”的顺序完成首次上电；
- 用万用表、示波器、限流电源定位常见故障；
- 区分“焊接问题、器件问题、设计问题、固件问题”；
- 用 AVRDUDE 读器件签名与熔丝位，烧录一个最小测试固件；
- 安全地拆焊、返修，不把焊盘拽掉。

**难度定位：**制造篇收尾。本章是动手最多的一章，建议在废板上先练拆焊。

---

## 12.1 工位与安全

最低配置：

- 恒温烙铁（可调温，尖头/刀头各一）；
- 助焊剂、吸锡带、焊锡丝；
- 放大镜/显微镜（或手机微距）；
- 万用表；
- 限流可调电源；
- 防静电垫/腕带；
- 镊子、热风台（拆贴片用）。

安全：

- 焊接烟雾要排风；
- 热风台温度高，远离可燃物；
- 上电前检查电源极性；
- 电解电容、TVS 反接可能爆裂，先确认方向。

## 12.2 焊接顺序：先低后高，先难后易

推荐顺序：

1. 最难的细间距 IC（QFP/QFN）先焊，避免周围器件挡住；
2. 小贴片（电阻、电容）；
3. 大贴片（LDO、连接器）；
4. 通孔器件（排针、按键、USB-C）；
5. 最后装高器件/易损器件。

每焊一类，检查一次：

- 有没有连锡；
- 有没有漏焊；
- 极性器件方向；
- 焊点是否光亮、润湿。

### 手焊 SOIC/SOP

- 先固定对角两个脚；
- 加助焊剂，用刀头拖焊；
- 用吸锡带清理多余锡；
- 放大镜检查连锡/虚焊。

### 手焊 QFN/DFN

- 先给焊盘上薄锡；
- 涂助焊剂，放器件，热风加热；
- 轻推器件，能自动回位说明润湿良好；
- 用放大镜/侧视检查侧面爬锡；
- 中心焊盘需要足够过孔/散热，避免浮起。

> **提示：**QFN 的“能通电”不等于“焊好了”。侧面爬锡、中心焊盘空洞、接地不良，都可能在温度变化后失效。首件建议 X-ray 或至少做热循环后的功能测试。

## 12.3 首次上电：八步法

```ill
kicad-ch12-bringup
```

图 12-1 首次上电的顺序。每一步都应有可观察的结果，而不是“感觉没问题”。

1. **目视**：有无连锡、器件方向、极性、异物；
2. **测短路**：万用表测 `VBUS`、保险丝后的 `+5V`、`+3V3` 对 `GND`，排查持续低阻；
3. **限流**：电源设 5 V、限流 50–100 mA；
4. **上电**：观察电流；异常立即断电；
5. **测轨**：分别测保险丝前的 `VBUS`、保险丝后的 `+5V`、LDO 输出的 `+3V3`。若 `VBUS` 正常而 `+5V` 为 0，查保险丝与连接；若 `+5V` 正常而 `+3V3` 为 0，查 LDO 输入/输出、焊接与负载短路；若该 LDO 有 EN 脚，再查 EN 电平，不要再去换保险丝。
6. **测电流**：空载电流是否合理（MCU 未编程时通常几 mA）；
7. **时钟/复位**：本板用内部 RC，没有晶振；先测 RESET 已释放为高。时钟是否工作，等烧录后用 PB3 翻转确认。
8. **编程**：接 ISP，读器件 ID，烧录测试程序；烧录后测 PB3 是否翻转，确认时钟与复位正常。

八步法里的“测轨”不是只测一个点。按下面三段逐点确认，才能把“USB 没电”“保险丝断”“LDO 没输出”分开：

```ill
kicad-ch12-power
```

图 12-2 上电后的三段电压测量。黑笔固定在 GND，红笔依次测 `VBUS`、保险丝后的 `+5V`、LDO 输出的 `+3V3`；先断电再换档。

### 用 AVRDUDE 读 ID 与烧录

ATtiny85 的 ISP 接线是 PB0/MOSI、PB1/MISO、PB2/SCK、RESET、VCC、GND（第 2 章）。[AVRDUDE](https://github.com/avrdudes/avrdude) 是开源编程工具；第一次连接先只做“读”，确认接线和目标电压：

```bash
# 连接后显式读签名；-p t85 会按 ATtiny85 校验
avrdude -c usbasp -p t85 -U signature:r:-:h

# 烧录 Intel HEX；确认供电为 3.3 V 后再执行
avrdude -c usbasp -p t85 -e -U flash:w:blink.hex:i
```

- `-c usbasp` 是编程器型号；用 Arduino as ISP、AVRISP mkII 时换成对应的 `-c`，不要照抄。
- `-p t85` 对应 ATtiny85；签名不匹配时先查接线、目标供电和芯片型号，不要改参数硬烧。
- `-e` 会擦除芯片；只想更新 Flash 时可先不加，确认流程后再用。
- 烧录前先读并记录熔丝位：`avrdude -c usbasp -p t85 -U lfuse:r:-:h -U hfuse:r:-:h -U efuse:r:-:h`。不要凭记忆写熔丝；改错时钟源会让芯片“再也连不上”。

> **警惕：**USBasp 克隆板的输出电压和 IO 电平不一定是 3.3 V。接 ATtiny85 前用万用表测 ISP 排针的 VCC/GND，确认目标电压与逻辑电平；若 USBasp 以 5 V 向目标供电，或 ISP 信号高电平为 5 V，可能把 5 V 加到本板 3.3 V 轨/输入脚，造成倒灌或超压。确认兼容后再连接，不要用 5 V 目标电压烧录。

> 依据：[AVRDUDE 8.1 手册](https://avrdudes.github.io/avrdude/8.1/avrdude.html) 的 *C. List of Programmers*（`usbasp`）、*C. List of Parts*（`t85` = ATtiny85）与 *E.1 Classic parts*（`signature` 存储器）；ATtiny85 的 ISP 引脚见器件数据手册 *Pin Descriptions* 与 *Memory Programming* 章节。

如果 AVRDUDE 报签名错，先做三件事：测目标板 3.3 V、测 ISP 六根线通断、确认 RESET 没有被按键持续拉低。不要一上来就换芯片。

### 最小测试固件从哪来

`blink.hex` 不是 KiCad 生成的。没有现成固件时，可以用 `avr-gcc` 编译一个只翻转 PB3 的程序：

```c
#define F_CPU 1000000UL
#include <avr/io.h>
#include <stdint.h>
#include <util/delay.h>

int main(void) {
    DDRB |= (1 << PB3);          /* PB3 输出 */
    for (;;) {
        PORTB ^= (1 << PB3);     /* 翻转 LED */
        for (uint8_t i = 0; i < 50; i++) {
            _delay_ms(10);       /* 50 × 10 ms ≈ 500 ms */
        }
    }
}
```

```bash
avr-gcc -mmcu=attiny85 -Os -o blink.elf blink.c
avr-objcopy -O ihex -R .eeprom blink.elf blink.hex
avrdude -c usbasp -p t85 -U flash:w:blink.hex:i
```

`F_CPU` 是告诉编译器的编译期常量，不会改变芯片的实际时钟；实际时钟由熔丝位/CLKPR 决定。ATtiny85 出厂默认时钟为 1 MHz（8 MHz RC 经 CKDIV8 分频，低熔丝 0x62）；只有确认已取消 ÷8 后才改为 8 MHz。若改过熔丝位，先读回时钟配置再改 `F_CPU`，否则延时和通信都会偏。`_delay_ms` 的单次精确延时上限约为 262.14 ms / F_CPU[MHz]；超过后 avr-libc 会降低分辨率、不再保证精确延时，所以 1 MHz 下 500 ms 建议拆成多次短延时（示例用 50 × 10 ms）。

> **边界：**这个固件只证明“供电、复位、时钟、PB3、LED 支路和 ISP 能工作”。它不测试按键、USB-C 供电握手或产品功能；不要把它当成整板验收。

### 电流异常的判断

| 现象 | 可能原因 |
| --- | --- |
| 电流接近限流值，电压被拉低 | 短路/器件反接/LDO 自激 |
| 电流为 0 | 未接通/保险丝断/连接器虚焊 |
| 电流略高但能工作 | 器件漏电/焊接残留/软件未休眠 |
| 电流随 LED 约 1 Hz 周期性变化 | 正常：blink 固件在翻转 LED；只要电压稳定、没有复位即可 |
| 电流无规律跳动，或随 LED 变化时电压跌落/复位 | 复位循环/电源不稳/接触不良 |

不要用“摸温度”代替测量。烫手说明已经严重过流；不烫也可能是空焊。

## 12.4 常见故障树

```ill
kicad-ch12-debug
```

图 12-3 从“不工作”到具体边界的故障树。先分“电源、复位、时钟、启动、外设”，再往下查。

### 不上电

- 检查 USB-C 的 CC 下拉；
- 检查保险丝/TVS 是否装反/击穿；
- 检查 LDO 输入/输出是否短路；
- 检查电源开关/跳线；
- 用外部电源直接给 `VBUS`，排除连接器问题。

### 上电但 MCU 不响应

- 测 RESET 是否为高（不应一直被拉低）；
- 测 VCC 是否在 3.3 V ±5%；
- 测晶振是否起振（若有）；
- 检查 ISP 接线（MISO/MOSI/SCK/RESET/GND）；
- 读器件 ID：读不到，先查焊接/接线，再怀疑芯片。

### 能编程但不运行

- 检查熔丝位（时钟源、BOD、RESET 使能）；
- 检查复位引脚是否被外设拉低；
- 检查电源纹波；
- 检查时钟源配置；
- 用最简程序（点灯）排除外设问题。

### USB 供电握手失败

本板只取电、不传数据，因此不要按“USB 设备识别”排查。重点检查：

- CC1/CC2 的 5.1 kΩ 下拉是否装对、是否虚焊；
- 换一根线、换一个充电器，排除线材和充电器问题；
- 测 `VBUS` 是否有 5 V，限流电源是否进入恒压/恒流；
- 检查 VBUS 的保险丝、TVS 和 LDO 输入是否短路；
- 如果用了 PD/QC 充电器，确认它没有因为协议不匹配而关断输出。

## 12.5 示波器怎么用才不误导

- 先用探头的地弹簧（短地线），不要用长地线夹测高频；
- 测电源纹波用 AC 耦合、20 MHz 带宽限制；
- 测晶振用 10× 探头，避免探头电容影响起振；
- 测复位/使能信号用 DC 耦合，看电平与时序；
- 触发点选在边沿，不要自由运行。

> **警惕：**用长地线夹测开关电源纹波，看到的是“探头环路拾取的噪声”，不是电源本身。先缩短地线，再下结论。

## 12.6 返修：拆得下，也要装得回

### 拆焊

- 先用助焊剂和新锡“混”一下旧焊点，降低熔点；
- 用吸锡带/吸锡器清理；
- 多引脚 IC 用热风均匀加热，或加低熔点合金；
- 不要硬拽；焊盘掉了，修复成本远高于多等 10 秒。

### 焊盘修复

- 断线：用细铜线+绿油/UV 固化修复；
- 焊盘脱落：找到同网络的过孔/测试点，飞线连接；
- 修复后必须重新测通断，并在文档里记录。

### 返修后的验证

- 通断/短路；
- 功能测试；
- 必要时做温度循环/振动（产品级）。

## 12.7 从首件到小批量：把调试变成测试

首件靠人 debug，小批量要靠测试治具/脚本。测试项要按这块板裁剪，不要照搬通用清单：

- 测试点要可探针接触；
- 生产测试固件要在 blink 示例上增加 PB4 按键读取（§12.3 示例只翻转 PB3）；自检项为翻转 LED、读按键。本板没有通信接口或传感器，不要把“通信/传感器”写进测试项；
- 测试项目：`VBUS`/`+5V`/`+3V3`、空载电流、ISP 签名、LED、按键；
- 记录每个板的测试结果与批次。

> **可重复性：**每块板用同一路 5.0 V、同一限流值（如 100 mA）测试，并把判定阈值写进记录表：`VBUS`/`+5V` 4.75–5.25 V，`+3V3` 3.14–3.47 V，空载电流相对首件基线偏差不超过 ±30%，LED 按约 1 Hz 翻转可见。按键测试前，先确认 PB4 已配置为输入并使能内部上拉，或确认板上的 10 kΩ 外部上拉已装配；否则悬空读数无效。按下时 PB4 < 0.3 V，松开时 > 3.0 V。阈值可按你的电源/LDO 精度调整，但一旦定下就固定使用。

测试点布局在第 6 章就应该考虑，不要等调试时才发现“探针没地方放”。

## 本章小结

- 首次上电按八步法检查各电源轨：`VBUS`、`+5V`、`+3V3` 分别测量。
- 故障树先分电源/复位/时钟/启动/外设，再往下查。
- 示波器测量要短地线、合适的耦合与带宽限制。
- 返修要控制热量，避免焊盘脱落；修复后必须复测并记录。
- 小批量要把 debug 转成可重复的测试。
- 编程先用 AVRDUDE 读签名与熔丝位，再烧录；签名错先查 3.3 V 供电与 ISP 接线，不要先换芯片。

## 练习

1. 在废板上练习拆焊一个 SOIC-8 和一个 0805 电阻，记录焊盘完整率。
2. 给 `usb_breath_led` 写一份“首次上电记录表”，包含电压、电流、现象、结论。
3. 设计一个最简测试治具（或测试点布局），能一次测完电源、编程、LED、按键。
4. 用 AVRDUDE 读一次签名和三个熔丝位，记录输出；再按 12.3 的 C 代码编译并烧录 PB3 闪烁固件，确认能读回、能运行。

## 验收

- 首件上电过程有记录，异常有解释；
- 能区分“焊接/器件/设计/固件”四类问题；
- 能解释 `VBUS` 与保险丝后 `+5V` 不同，并能据测量值定位开路保险丝或 LDO 输入问题。
- 能读出 ATtiny85 的签名与熔丝位并烧录最小固件；签名不符时有供电/接线排查记录。
- 返修后的板子通过通断与功能测试；
- 测试点可被探针稳定接触。
