# 第 11 章：打样与组装——从下单到首件验证

> **开门一句话：**下单是把设计假设交给现实检验。首件就是第一次考试，分数由板和装配一起给。

## 学习目标

读完这章，你能做到：

- 填写一张完整的打样/组装订单，并解释每个选项的来源；
- 区分“板厂能力”和“组装厂能力”，知道哪些参数要分别确认；
- 准备钢网、贴片坐标、BOM，并核对三份组装文件对应同一设计版本；
- 用 InteractiveHtmlBom 等社区工具辅助手工装配，并知道它们的适用边界；
- 设计一份首件检查表与记录模板，能在上电前发现大部分装配问题。

**难度定位：**制造篇。本章偏流程，但每一步都有可执行的检查项。

## 11.1 打样订单：每个选项都要有依据

一个典型的 PCB 打样订单包含：

| 选项 | 常见值 | 依据 |
| --- | --- | --- |
| 层数 | 2 / 4 / 6 | 布线密度、阻抗、EMC |
| 板厚 | 1.6 mm | 结构/连接器/外壳 |
| 铜厚 | 1 oz / 2 oz | 电流、散热 |
| 板材 | FR-4 | 成本、频率、环境 |
| 阻焊颜色 | 绿/黑/白/蓝 | 外观、检查对比度 |
| 表面处理 | 无铅喷锡/沉金 | 焊接、存储、细间距 |
| 最小线宽/间距 | 0.15/0.15 mm | 设计规则 |
| 最小孔径 | 0.3 mm | 设计规则 |
| 阻抗控制 | 否/是 | 高速信号 |
| 拼板 | 否/是 | 批量、工艺边 |

### 表面处理怎么选

- **无铅喷锡（HASL）**：便宜、可焊、平整度一般；适合手焊/普通贴片。
- **沉金（ENIG）**：平整、适合细间距/QFN/BGA；成本高，存储要求高。
- **沉锡/沉银**：特定工艺，存储与焊接窗口更窄。

教学板用无铅喷锡即可。细间距 QFP 或少引脚 QFN 往往更适合沉金，因为焊盘更平；但工艺选择要和实际贴片厂确认：他们用钢网、锡膏还是点胶、是否二次回流、存储和保存周期如何，都会改变结论。不要只按封装就定表面处理。

### 阻焊颜色

颜色不影响电气，但影响：

- 目视检查对比度（黑色难看清走线）；
- 丝印可读性；
- 外观/产品定位。

教学板建议绿色或蓝色，便于看清铜线与丝印。

## 11.2 组装订单：板厂和组装厂是两家

PCB 打样和 PCBA 组装常常是两家工厂，即使同一个平台下单，也要区分：

- **板厂**关心：层数、板厚、铜厚、孔径、线宽、阻焊、表面处理、拼板；
- **组装厂**关心：BOM、坐标、钢网、器件封装、贴片方向、测试要求。

常见错误：

- 只给板厂 Gerber，不给组装厂坐标/BOM；
- BOM 里的封装与坐标文件不一致；
- 坐标原点与板厂/组装厂约定不同；
- 连接器方向、极性器件方向没有标注。

> **提示：**在 `fab/README.txt` 里画一张“板子方向”的示意图（或用文字描述），标明 USB-C 朝哪边、pin 1 在哪、LED 极性。组装厂会感谢你。

### 组装文件三件套

组装厂真正要的是三份能互相对上的文件：

| 文件 | 典型内容 | 本板核对点 |
| --- | --- | --- |
| BOM | 位号、值、封装、数量、MPN/LCSC | 与原理图/PCB 的位号一致；DNP 项明确 |
| 坐标文件（CPL/POS） | 位号、Mid X、Mid Y、层、旋转角 | 原点与 Gerber/钻孔一致；旋转角以工厂模板为准 |
| Gerber + 钻孔 | 铜层、阻焊、丝印、板框、孔 | 层数、板框、孔位与坐标同源 |

三份文件必须对应同一设计版本（同一份 BOM、同一块板）；CPL、Gerber 与钻孔的坐标原点、单位必须一致。常见事故是 BOM 改了值、坐标文件还是旧的；或者 CPL 的旋转角按 KiCad 习惯写，工厂按自己的零度读。首件前用位号抽样对照：BOM 里有的，坐标里要有；坐标里有的，板上要能装。

> **提示：**KiCad 的 `kicad-cli` 能生成通用 BOM/坐标（第 10 章）。JLCPCB 等平台要求自己的列名和旋转角约定，可在导出后用脚本改列，也可用社区插件 `kicad-jlcpcb-tools`（见 11.8）生成平台格式；不要把它当成“免检查”。

## 11.3 钢网与锡膏

贴片组装需要钢网（stencil）。钢网开口通常与焊盘一致，但根据工艺会做调整：

- 细间距焊盘：开口略缩小，减少连锡；
- 大焊盘/散热焊盘：开口分割成网格，减少锡量；
- QFN 中心焊盘：开口分区，避免浮起。

钢网厚度常见 0.10–0.15 mm。锡膏类型要与器件间距匹配； fine pitch 用更细的锡粉（Type 4/5）。

手焊教学板可以不用钢网：用针筒点锡膏，或用烙铁+焊锡丝。但 QFN/DFN 没有钢网很难保证一致性。

## 11.4 组装流程

```ill
kicad-ch11-assembly
```

图 11-2 印刷 → 贴片 → 回流 → 检验。每一段都要有可追溯的批次与参数。

1. **印刷**：钢网对齐，锡膏厚度均匀；
2. **贴片**：按坐标文件放置器件，注意极性与 pin 1；
3. **回流**：按锡膏曲线升温/保温/回流/冷却；
4. **检验**：目视/AOI/X-ray（按需）；
5. **测试**：上电、功能、编程；
6. **分板/清洗/包装**。

> **湿敏器件（MSL）：**拆封前看包装上的 MSL 等级与湿度指示卡；超过车间寿命或受潮的器件，按数据手册的烘烤条件处理后再回流。卷带/托盘能否烘烤以厂商说明为准，不要用家用烤箱猜温度。MSL 等级、拆封时间和烘烤记录属于来料/工艺记录，不必塞进设计 BOM，但要随批次留档。

### 用 InteractiveHtmlBom 辅助手工装配

手工焊一批板时，最费时间的是“这个位号在哪”。[InteractiveHtmlBom](https://github.com/openscopeproject/InteractiveHtmlBom)（MIT）把 BOM 表和板图放进同一个离线 HTML：点 BOM 行会高亮板上位置，点板上的封装会反查 BOM；可以按值/封装分组，标记已焊，隐藏已完成的器件。生成的页面完全自包含，不需要联网。

用法（可选）：

1. 在 PCB 编辑器里安装并启动插件（PCM 或插件目录，具体步骤以项目 wiki 为准）；
2. 用当前 `.kicad_pcb` 生成 HTML，按需要包含丝印/fab 层与网络信息；
3. 打开生成的 HTML，按位号或值筛选，边焊边勾选；
4. 焊完后用“未焊/已焊”清单与 BOM 对账，再上电。

它只读 PCB 数据，生成的是装配辅助页面，不是 Gerber/坐标/BOM 的替代品；插件版本与 KiCad 主版本要写进记录。

### 回流曲线

不同锡膏有不同曲线，但一般包含：

- 预热区：缓慢升温，激活助焊剂；
- 保温区：温度均衡，减少热冲击；
- 回流区：超过熔点，形成焊点；
- 冷却区：控制晶粒，避免脆裂。

不要用“烤箱最高温”代替曲线。没有温度曲线时，至少按锡膏厂商推荐值设置，并用测温板验证。

## 11.5 首件检查：上电前能发现的问题

首件（First Article）不是“第一块板随便看看”，而是系统性核对：

| 检查项 | 方法 | 失败后果 |
| --- | --- | --- |
| 板框/孔位 | 卡尺/对比 Gerber | 装不进外壳 |
| 器件方向 | 对照坐标/BOM/丝印 | 上电烧器件 |
| 极性器件 | LED、二极管、电解电容 | 不亮/爆电容 |
| 焊点质量 | 目视/放大镜/AOI | 虚焊/短路 |
| 连锡 | 细间距 IC、连接器 | 短路 |
| 空焊 | QFN/连接器 | 不工作 |
| 阻焊/丝印 | 目视 | 可读性/绝缘 |
| 铜皮/划伤 | 目视 | 断路/短路 |
| 二维码/批次 | 扫描 | 追溯失败 |

### 上电前的“三用表检查”

1. 用万用表检查 `VBUS`、保险丝后的 `+5V`、`+3V3` 各对 `GND` 是否存在持续低阻；电容充电造成的瞬时读数变化不单独判为短路；
2. 检查保险丝（或 0 Ω 电阻）两端是否从 `VBUS` 连到 `+5V`，记录开路/阻值异常；
3. 测每个电源测试点对地电阻，记录基线；
4. 检查所有 IC 的 pin 1 方向；
5. 检查连接器是否装反/偏位。

### 首件记录模板

首件检查要有记录，否则“检查过了”无法复核。建议一行一块板，至少记录：

| 字段 | 记录内容 |
| --- | --- |
| 批次/板号 | 日期、批次、板序号 |
| 目视 | 连锡、偏位、极性、异物、丝印 |
| 电源对地 | `VBUS`、`+5V`、`+3V3` 对 `GND` 的阻值或 `OL` |
| 上电 | 电源电压、限流值、实际电流 |
| 轨电压 | `VBUS`、`+5V`、`+3V3` 的实测值 |
| 编程 | 器件 ID、烧录结果 |
| 功能 | LED、按键、复位 |
| 结论 | 通过 / 返修 / 报废，签字 |

不要把“和上一块差不多”当记录。阻值、电压和电流是判断“有没有装错/短路”的基线；没有基线，返修时只能靠猜。

> **警惕：**不要第一次上电就用大电流电源。用限流电源，先设 50–100 mA，电压从 0 慢慢升到额定值；如果电流异常，立即断电。

## 11.6 小批量与拼板

小批量（10–100 片）时，拼板能显著提高效率：

- 工艺边 + V-Cut/邮票孔；
- 阵列排布，留出铣刀路径；
- 基准点（fiducial）放在工艺边；
- 每块小板保留独立丝印/位号。

[KiKit](https://github.com/yaqwsx/KiKit)（MIT）可以生成拼板、工艺边、V-Cut/邮票孔，并导出 Gerber；它提供 GUI、CLI 和脚本三种入口。批量前先用一块废板验证拼板间距、铣刀路径和分板毛刺，再确认工厂支持的拼板方式与最小间距。拼板改了板框与基准点，必须重新跑 DRC，不能沿用单板的报告。

> **边界：插件是加速器，不是交付前提。**本章 `usb_breath_led` 的最小制造包（第 10.1 节标“必需”的 Gerber、钻孔、坐标、BOM 与 `fab/README.txt`）只用 KiCad 自带的 GUI 和 `kicad-cli` 就能生成；不装任何第三方插件也能完成打样与组装。KiKit、`kicad-jlcpcb-tools` 属于可选工具，用来省步骤，不用来定义“正确”。若插件安装失败、版本与 KiCad 10 不匹配，或在无网络/CI 环境中不可用，直接跳过相关段落，按第 10 章的命令导出即可，不要卡住交付。

## 11.7 成本与时间的现实

打样成本由这些因素决定：

- 层数/板厚/铜厚；
- 板面积；
- 孔径/线宽是否压极限；
- 表面处理；
- 组装点数/双面；
- 钢网/首件/测试；
- 加急。

教学项目不必追求“最便宜”。第一版的目标是“能验证设计”，不是“量产成本”。等设计稳定后，再优化拼板、器件选型和工艺。

## 11.8 从开源项目与标准继续学习

本章的工具只解决“少点几下”；真正的判断来自对比和验收语言。三个方向：
以下链接访问于 2026-11-22；社区仓库的默认分支会变化，复现时记录 commit/tag 或发布版本。

1. **读完整工程，不读截图。** [KiCad 10.0 源码镜像中的 demos](https://github.com/KiCad/kicad-source-mirror/tree/10.0/demos) 有从原理图到 PCB 的完整工程。读的时候先看工程规则、叠层、网类，再自己按第 10 章导出一次制造包，最后看布线。能复现它的制造包，比“看起来画得漂亮”更有价值。
2. **用标准建立验收语言。** 先和组装厂约定验收等级（例如 IPC-A-610 的 Class 2），再按该等级的条款自查；IPC-2221 则覆盖设计通用要求。标准文本通过标准组织、公司许可或图书馆获取，本书不复刻正文。教学板也要把“焊点润湿、连锡、极性、清洁度”写成可检查的条目，而不是口头说“焊好了”。
3. **把社区工具当“可替换的实现”。** 本章用到的 [InteractiveHtmlBom](https://github.com/openscopeproject/InteractiveHtmlBom)、[KiKit](https://github.com/yaqwsx/KiKit)、`kicad-jlcpcb-tools` 都是 MIT 许可的社区项目；它们的输出必须回到 BOM、坐标与 Gerber 三件套核对。工具升级后先在小批量上验证，不要把“插件能点”当成“工厂能收”。

> **提示：**读开源硬件项目时，先看它的 `fab/`、`README`、DRC 规则和 BOM，再看布线。能复现别人的制造包，比“看起来画得很漂亮”更有学习价值。

## 本章小结

- 打样订单的每个选项都要有设计依据；板厂与组装厂的能力要分别确认。
- BOM、坐标（CPL）与 Gerber/钻孔必须对应同一设计版本；CPL、Gerber 与钻孔的坐标原点、单位一致；钢网按组装工艺单独确认；
- 回流曲线按锡膏厂商推荐值设置，并用测温板验证；
- 首件检查是系统性核对，要留下阻值/电压/电流基线与签字记录，不是“看一眼”；
- 上电前用限流电源和三用表做基础检查；社区工具是可选加速器，输出仍要回到三件套核对。

## 练习

1. 为 `usb_breath_led` 填一张打样订单，给每个选项写一句依据。
2. 写一份首件检查表，至少包含 10 项，并标注“目视/工具/上电”三种方法。
3. 查一家常用板厂的工艺能力表，把你设计中的极限参数与它对比，列出需要调整的项。
4. 用 InteractiveHtmlBom 生成一次装配页面，随机抽 10 个位号，在页面与 BOM 之间双向核对。

## 验收

- 订单选项与设计文件一致；
- BOM 与坐标（CPL）的位号能互相对上；坐标原点、层信息与 Gerber/钻孔一致；
- 首件检查表可执行，不依赖“经验丰富的人看一眼”，并留下实测基线；
- 最小制造包能只用 KiCad 自带工具复现；插件不是验收条件，详见 11.6 的边界说明；
- 你能说出至少三个会导致“首批全废”的装配错误。
