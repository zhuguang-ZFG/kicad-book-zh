# docs/ 预览与版式检查稿

本目录保存封面、徽记和章节过渡页的版式检查图，不是书稿正文，也不是 KiCad 操作截图。它们不参与 PDF 构建；页脚页码来自早期版本（`/135`），早于当前 PDF，因此图中的页码只能作为历史对照。

| 文件 | 用途 |
| --- | --- |
| `preview-cover.png` | 封面版式预览 |
| `emblem-sheet.png` / `emblem-sheet.html` | 徽记样张与对照页 |
| `transition-*.png` | 章节过渡页版式检查稿；含 `check`、`final`、`p037` 等历史轮次 |

发布前若要保留这些图，应从当前 PDF 重新导出；否则应删除，避免被误认为当前页面或软件截图。
