# 附录 C：常见错误与排查表

> 本附录按“现象 → 可能原因 → 检查方法 → 处理”组织。先查最便宜的项，再拆贵的件。

## C.1 原理图/ERC

| 现象 | 可能原因 | 检查方法 | 处理 |
| --- | --- | --- | --- |
| ERC 报 `Pin not connected` | 引脚悬空/线没落到端点 | 放大看端点，跑 ERC 跳转 | 补线/加 No Connect |
| ERC 报 `Input Power pin not driven by any Output Power pins` | 电源符号没接/网络名不一致/电源输出未接 | 查电源符号与网络标签 | 补电源/统一网络名 |
| ERC 报 `Label not connected` | 标签连接点未接入网络 | 核对标签锚点是否落在线上，并高亮两端引脚 | 接好标签，再核对拼写和作用域 |
| ERC 报 `Unconnected wire endpoint` | 可能只是已连接标签之后多了一截线 | 跳转到悬空线端，用网络高亮查预期引脚（见 2.3） | 若同网且线尾无用，修剪线尾；若不同网，查实际断点 |
| ERC 报 `Conflict problem between pins` | 两个输出接同一网络，或引脚组合违反 Pin Conflicts Map | 查网络上的引脚类型与冲突映射 | 改电气类型/加缓冲/断开 |
| 符号显示“未找到” | 库表路径断/库未安装 | 看 `sym-lib-table` | 修路径/安装库 |
| 封装字段为空 | 未分配封装 | Assign Footprints | 分配并核对 |
| BOM 参考号重复 | 复制粘贴未重新编号 | 看 Reference | 重新编号（Annotate） |

## C.2 PCB/DRC

| 现象 | 可能原因 | 检查方法 | 处理 |
| --- | --- | --- | --- |
| DRC `Clearance violation` | 线/焊盘太近 | 看报告数值与位置；右键可跑 clearance resolution | 移线/改规则 |
| DRC `Track width` | 实际线宽低于板级最小线宽或自定义规则下限；网类线宽本身只是布线优选值，不单独触发 DRC | 看报告数值与约束来源；需要时用 constraints resolution tool | 加宽到要求值，或修正板级/自定义规则 |
| DRC `Annular width` | 焊盘/过孔的环宽低于板级最小值，或超出规则范围 | 算环宽，查板级/自定义规则 | 改焊盘/孔径 |
| DRC `Hole clearance violation` | 孔到铜太近 | 看孔位；右键跑 clearance resolution | 移孔/加间距 |
| DRC `Board edge clearance violation` | 铜到板边太近 | 看板边与铜对象 | 内缩/改规则 |
| DRC `Courtyards overlap` | 器件占位重叠 | 看 2D/3D | 移器件/确认可叠 |
| DRC `Silkscreen clipped by solder mask` | 丝印压到阻焊开窗/焊盘 | 看丝印层与 `F.Mask` | 移丝印/改封装 |
| DRC 对话框 `Unconnected Items` 标签 | 仍有飞线/网络未连 | 看飞线与标签页 | 布线/补过孔/调整铺铜 |
| DRC `Schematic parity` 检查 | PCB 与原理图不一致（仅在启用 parity 且随工程运行时检查） | 看差异列表 | 更新 PCB/原理图 |
| 铺铜后有孤岛 | 最小岛设置/无连接 | 看铺铜 | 删岛/加过孔 |
| 3D 模型缺失 | 路径/格式 | 看封装 3D 设置 | 修路径/转 STEP |

## C.3 制造文件

| 现象 | 可能原因 | 检查方法 | 处理 |
| --- | --- | --- | --- |
| 工厂说缺层 | 导出时没选全 | 对照叠层 | 重导 |
| 钻孔与焊盘偏移 | 原点不一致 | 叠加钻孔/Gerber | 统一原点 |
| 阻焊盖住焊盘 | 阻焊层反相/开窗错 | Gerber Viewer | 检查 `F.Mask` |
| 丝印糊/压焊盘 | 线宽/位置 | 看丝印层 | 调线宽/移位置 |
| 只有某个位号的贴装落点偏移 | 封装锚点未对准所需贴装中心 | 用同面已知中心的器件作参照（见 10.4） | 核对并修正该位号，不平移整份 CPL |
| 落点正确但贴装方向错 | 平台角度约定或器件方向不一致 | 对照 pin 1、阴极与工厂参考视图 | 确认变换规则再修订；不盲加固定角度 |
| 底层 X 坐标镜像 | 底面坐标约定不一致 | 按同一视角叠加底面数据（见 10.4） | 工厂明确要求时才改底层 X 符号 |
| BOM 缺料号 | 字段空 | 看 CSV | 补 MPN |
| 拼板 V-Cut 位置错 | 拼板文件 | 看拼板图 | 改拼板 |

## C.4 上电/调试

| 现象 | 可能原因 | 检查方法 | 处理 |
| --- | --- | --- | --- |
| 上电电流到限流 | 短路/器件反接 | 断电测电阻 | 找短路/换器件 |
| 无电流 | 连接器/保险丝/开关 | 测电压 | 修连接 |
| 3.3 V 偏低 | LDO 输入不足/负载过大/保险丝开路 | 测保险丝前 `VBUS`、后 `+5V`、输出 `+3V3` | 查 CC、保险丝、LDO 与负载 |
| 3.3 V 偏高 | LDO 坏/反馈错 | 测反馈 | 换 LDO/查电路 |
| MCU 不复位 | RESET 被拉低 | 测 RESET | 查按键/电容 |
| 晶振测不到波形（仅外部晶振） | 时钟源配置、探头负载、负载电容或焊接 | 先查时钟配置；优先测缓冲时钟输出（见 12.5） | 排除探头负载后，再检查电容与焊点 |
| 读不到芯片 ID | ISP 接线/焊接 | 测通断 | 修线/重焊 |
| AVRDUDE 报签名错/`target doesn't answer` | 目标未供电、ISP 线序错、RESET 被拉低、USBasp 电压不对 | 测 ISP 排针 3.3 V、六线通断、RESET 电平 | 修供电/线序/驱动，确认 3.3 V 后再烧 |
| 烧录后 LED 闪烁周期不对 | `F_CPU` 与实际时钟不一致（出厂 1 MHz，不是 8 MHz） | 读熔丝位/CLKPR，确认 CKDIV8 | 改 `F_CPU`，或确认已取消 ÷8 |
| USB 不供电/电流不足 | CC 下拉缺失/线材/充电器/保险丝 | 测 CC1/CC2、保险丝前 `VBUS` 和后级 `+5V` | 补 5.1 kΩ/换线/查保险丝 |
| 能编程不运行 | 熔丝/时钟/复位/外设 | 先读回熔丝、CLKPR 与 RESET 电平，和数据手册或已知正常板对照 | 确认原因后才改有记录的熔丝；先查外设/时钟，不要凭记忆写熔丝 |
| 发热严重 | 短路/过流/自激 | 限流/测温 | 断电排查 |

## C.5 仿真

| 现象 | 可能原因 | 检查方法 | 处理 |
| --- | --- | --- | --- |
| 没有波形 | `OP`、`PZ` 只在日志中给结果；`TRAN` 或 `AC` 可能没跑完或没选信号 | 确认活动分析页、日志与 Signals（见 13.8） | 先解决运行错误；需要曲线时选对应的分析类型和信号 |
| 结果与手算差几个数量级 | 单位后缀或模型参数错 | 查生成的 SPICE 网表（见 13.8）；裸 SPICE 的 `1M` 是 `1e-3` | 若本意是一百万，裸 SPICE 写 `1Meg` 或 `1e6`；重跑并对照手算 |
| 不收敛 | 拓扑有误、缺少电源或地、模型引脚映射错误、初值不合适 | 先读仿真日志，再核对拓扑、电源与地、模型引脚映射（见 13.8） | 有误先修正；确认无误后，才考虑调整初值或收敛设置 |
| AC 结果异常 | 源没设 AC/探针错 | 看源属性 | 设 AC 1/改探针 |

## C.6 Git/协作

| 现象 | 可能原因 | 检查方法 | 处理 |
| --- | --- | --- | --- |
| diff 巨大但没改电路 | 编辑器重排/版本升级 | 看 diff 类型 | 单独提交升级 |
| 别人打开缺库 | 绝对路径 | 看库表 | 改相对路径 |
| 冲突无法合并 | 二进制/大文件 | 看文件类型 | 用文本/分工 |
| 旧工程打不开 | 新版本保存过 | 看版本 | 用对应版本打开 |
| 3D 模型丢 | 路径变量 | 看模型设置 | 修路径/打包 |

## C.7 一张“先做什么”的顺序

遇到问题，按这个顺序，通常能最快缩小范围：

1. **能不能复现**：换一块板/换一个工程，问题是否相同；
2. **是电源还是信号**：先测电源轨，再测信号；
3. **是设计还是装配**：对照 Gerber/坐标/BOM，还是实物；
4. **是单点还是批量**：一块板 vs 多块板，指向焊接/器件/设计；
5. **是硬件还是固件**：最简程序/旁路外设，逐步排除。

> **提示：**每次排查只改一个变量。一次改三个地方，即使好了，也不知道是哪一个起了作用。
