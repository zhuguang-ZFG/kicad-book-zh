# KiCad 从原理到制板

*CC BY-NC-SA 4.0 © KKiCad 教学组 2026*

## 概览

本书是 KiCad 10.0.x 的中文教学书，覆盖从原理图绘制、PCB 设计、制造输出到调试全流程，以一块 USB 供电的桌面呼吸灯为贯穿全书的教学项目。全书共 15 章、4 篇附录、约 14.0 万字符（5.6 万汉字，按章节 Markdown 源文件统计），含 61 个手绘 SVG 资产，其中 36 幅教学插图（前言 1 幅、正文 35 幅），另有 10 张来源与许可可追溯的实物照片，并附 19 张 KiCad 10 官方界面截图，以及完整的内容检查与构建脚本。书中以一块 USB 呼吸灯（`usb_breath_led`）作为贯穿案例，但**不随书附带成品 KiCad 工程文件**；所有步骤均由读者按章节自行建立。

```bash
# 构建 HTML
cd yuyu-book
PYTHONPATH=. python -m yuyu_book --mermaid source

# 构建 PDF
PYTHONPATH=. python -m yuyu_book --mermaid source --pdf

# 内容检查
python ../tools/check_book.py
```
